# How to Change Any Villager's Skin and Name

This is about Villagers Reborn's new feature that lets you change the name and skin of any villager in-game.  
It also adds height and width sliders so you can customize villagers' appearance.

<br>

- First, click the new button in the top-right corner.

- In the new menu, you can type any name you want for the villager.

- You can also copy and paste the **"Image Link"** from any skin on Skindex and it will automatically update in-game.

- Or you can click the **"Open Skins Folder"** button and manually save any downloaded skin you want there. Then, simply type the full skin file name into the **"Skin"** field, including **".png"** at the end with no spaces.

- I've also added height and width sliders for villagers, so you can make them taller or shorter, as well as wider or slimmer.

<br>

## Notes:

- The sliders work much better when you use the same value for both sliders.

- You can have more than one skin in the same villager's folder and simply switch between them in-game by changing the skin name, although I recommend keeping only one **".png"** file per villager.
  
<br>

Once you're done with all your changes, just click **"Save Changes"** and you're all set!
